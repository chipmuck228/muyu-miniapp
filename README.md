# 小叩木鱼

一个敲木鱼、积专注、圆心愿的微信小程序。TypeScript + 微信云开发，界面走 Skyline，木鱼和青烟用 WebGL 绘制。

## 功能一览

### 入堂

- 冷启动先过一段大殿过场（「木 鱼 · 轻叩一声 · 万缘放下」），点屏幕可跳过。首次约 4 秒，之后 0.7 秒。
- 过场底下一行农历日子和时辰（「丙午年 九月廿三 · 黄昏」），逢春节、中秋等节日写节日，初一十五写「宜静心」。农历取自 `Intl` 的中国历，机型不支持就不显示。首次打开另有「轻触进入」提示。
- 首次进入先按「随机专注」布置香案，再弹出「今日功课」让用户选；之后直接接着上次的功课。

### 香案（敲木鱼）

- **敲击**：点木鱼有敲击声、震动、飘字（「专注 +1」或「静心 / 专注 / 加油…」）、一圈光晕、两道波纹和 3D 下压回弹。拖动木鱼可以旋转。自动敲用轻震。
- **里程碑**：今天第一下飘「今日第一叩」或「连续第 N 天」，整百、一百零八、心愿过半、升称号时也飘一句大字，同一句每次打开只飘一次。
- 当天还没敲过时，木鱼周围一圈光慢慢呼吸，下面写「轻触木鱼」。
- **自动**：右下角「自动」开关，每 0.8 秒敲一下。只在本次打开内有效。
- **计数**：每一下同时计入总专注、当天次数和当前心愿，并按来源（亲手 / 自动）分开记账。敲击在端上合并后批量上传。
- **今日功课**：顶部点「切换」打开底部面板，选一个进行中的心愿、「随机专注」或「＋ 立新愿」。
  - 心愿模式显示「当前 / 目标」、进度条、今日叩数和期限（「还剩 N 天」/「已过期限」）；随机模式显示「今日 N」。
  - 面板里每个心愿下有一道进度线，当前的那个带一个亮点。在面板里点「＋ 立新愿」立好的愿直接设成今日功课。
  - 上次的心愿完成或删除后，自动换到下一个进行中的心愿，都没有就回到随机专注。
  - 香案左侧有一列竖排功课名，字色随进度渐变；晨曦天空也随进度慢慢显出来。
- **木鱼材质**：紫檀、黄花梨、琉璃、玉，四种都免费，选择存在本机。换了以后名字在色点旁亮一下。
- **主题点缀**：夜、墨、霞三套主题下，顶部进度、期限、「自动」「定课」等字也换成银蓝、骨白、霞红。
- **青烟**：一缕随主题变色的烟，有弹窗时隐去。不支持 WebGL 的机型退回 canvas 版。
- **心愿圆满**：敲满目标的那一下响一声钟钵、长震一下，弹出「心愿圆满」卡片（莲花、光晕、落英，写着历时几天），可以「查看证书」，或「继续敲击」自动换到下一个心愿。
- 可以转发给朋友或分享到朋友圈。

### 定课

右下角「定课」打开面板，有两部分：

- **成品定课**：声音、主题、木鱼音色、自动敲节奏、时长和收尾都配好，点一下就开始。

  | 定课 | 场景 | 氛围 / 主题 | 木鱼音色 | 时长 | 收费 |
  |---|---|---|---|---|---|
  | 雨窗片刻 | 工作间隙，停一下 | 雨声 / 晨 | 默认 | 3 分钟 | 免费 |
  | 松间慢叩 | 想慢慢敲一会儿 | 松风 / 墨 | 低沉，节奏放慢 | 5 分钟 | 静心包，可完整试一次 |
  | 夜里收心 | 睡前，把今天放下 | 炉火 / 夜 | 轻柔，越敲越慢 | 10 分钟 | 静心包，可完整试一次 |

- **自己敲**：「一炷香」3 / 5 / 10 分钟（到点即止），或「一串念珠」108 下（敲满即止）。免费。面板里做成两行小签。

规则：

- 手敲、自动都算数，定课里的敲击照常计入专注和心愿。
- 离开香案时计时暂停，回来接着走；提前「收起」，已敲的照样计入。
- 成品定课结束时氛围慢慢淡出，再响一声钟钵，弹出小结；之后换回用户自己设的氛围和主题。自己敲的小结也送一句收尾语，并写上今日共几叩。
- 试用记录存在本机。试用中途收起也算用掉。

### 心愿

- **心愿列表**：分「进行中」和「已圆满」两组。进行中的是卡片：名字、百分比、进度条（九成以上发亮）、今日叩数、期限、「今日功课」标记和「详情」；已圆满的一行一枚小印（了结的是金印）和圆满日期。点进行中的心愿会把它设为今日功课并回到香案；长按可回堂敲击、看详情、改愿、删除。首次加载有占位行，空列表有立愿按钮和几个心愿灵感。
- **立愿 / 改愿**：心愿名最多 20 字，带字数和灵感小签；专注目标可选 100 / 500 / 1,000 / 5,000 / 10,000，或在第六格自定（只收数字，最多 999,999），下面估算一秒一叩要多久、每日 108 叩要几天；期限有「七日 / 一月 / 百日」快捷，写成「2026年12月1日 · 还剩 30 天」。改愿时可以删除心愿。心愿数量不限，免费。
- **心愿详情**：状态、期限、大号百分比、来源构成；一句往前看的话（有期限算每天要敲几下，没有就按近七日的节奏估几天圆满）；坚持天数、日均、最多一日；「近十四日」柱状图（今天和最高那天标数）；最近 10 天的叩击记录。进行中的心愿有一枚「惊喜封存中」；已圆满的可以「了结」（愿已成真），可「查看证书」，有壁纸时可「存壁纸」。

### 证书

- 每个已完成的心愿有一张证书：象牙纸、线描莲花、云头四角、淡淡的「愿」字水印、按圆满先后编的「愿字第 N 号」、心愿名（太长就缩字或折两行）、共积专注、来源构成、中文数字的日期（「二〇二六年十月二十日」）和白文「静心印证」印。
- 多张证书横排成一列小签，可左右滑。「保存相册」，或「分享」（图片分享菜单，可发朋友、朋友圈、收藏；老版本退回发文件），长按证书也可以。免费。
- 还没有证书时，显示离圆满最近的心愿，点一下回堂接着敲。

### 静心（我的）

- **今日一句**：按日期取一句诗文或短句，同一天不变。
- **称号**：`utils/constants.ts` 里的 9 级按总专注显示，带进度和「再 N 叩，至「下一级」」。
- **统计**：连续天数、今日叩数、心愿圆满数，以及近五周的日历热力图（格子里写日子，深浅按这几周最多的那天分四档，点格子看当天次数）。
- **静心包卡片**：没开的人看到一张卡，写着包含什么，点「开启」付款。
- **设置**：音效、震动、氛围、主题。选了氛围先试听几秒再淡出；锁着的选项带一把小锁。
  - 氛围：无 / 雨声 / 钟钵免费；白噪 / 溪流 / 松风 / 炉火属于静心包。
  - 主题：晨免费；夜 / 墨 / 霞属于静心包。
- 点带锁的选项直接进入付款。每次进入本页会续查已付款但还没开通的订单，并复核是否已退款。

### 静心包（付费）

一次付款，永久开启，不是订阅。走普通微信支付（JSAPI）。

- 包含：两套付费定课（松间慢叩、夜里收心）、四种高级氛围、三种高级主题。
- 三个购买入口：静心页点带锁的氛围或主题；定课面板里点试用过的付费定课；试用小结卡片上的「开启静心包」。
- 价格由 `wxpay` 云函数配置（单位分，示例 600 = ¥6）。
- 服务端也会校验：未开通的用户设不了付费氛围和主题。

### 渠道合作

静心页底部的「渠道合作」入口。

- **渠道商**：提交申请 → 管理员授权 → 用激活码（6 位，48 小时有效）激活 → 生成自己的推广码，查看推广用户（可按月份筛选、按标识搜索）。可以申请解绑，需要管理员批准。
- **用户归属**：用户首次扫某个渠道的推广码，就永久归到这个渠道，之后不能改。
- **渠道管理**：管理员处理绑定和解绑申请，查看、重发激活码，解绑渠道，清空记录。系统还没有管理员时，第一个打开「渠道管理」的微信自动成为管理员。

佣金还没有接上，见文末「尚未完成」。

## 声音

- 敲击声、雨声、钟钵用云存储里的录音，清单在 `miniprogram/utils/audioCatalog.ts`。
- 没配录音或下载失败时（包括本地模拟模式），全部改用端上合成的声音，不会没声：
  - 敲击声和定课结束的钟声：`miniprogram/utils/knockSynth.ts`
  - 各种氛围：`miniprogram/utils/ambienceSynth.ts`
- 定课的低沉、轻柔两种木鱼音色还没有专门录音，现在用默认敲击声放慢、放轻代替。
- iOS 静音拨片打开时照样出声。

## 数据存放

- **云数据库**：
  - `users`：总专注、设置、是否开通静心包等
  - `wishes`：心愿、进度、按来源计数、每日记录
  - `daily_hits`：每人每天的次数
  - `premium_orders`：付款订单
  - `channel_*`：渠道相关的几张表
- **云存储**：音频、晨曦图、渠道二维码。
- **本机**：上次的功课、木鱼材质、待确认的订单号、试用过的定课。

### 本地模拟模式

开发版专用，不需要云开发权限也能调界面和流程。云函数调用由 `miniprogram/utils/devMock.ts` 在本地模拟。

- 开发者工具「添加编译模式」，启动参数：
  - `mock=1` 开，`mock=0` 关，`mock=reset` 重置示例数据
  - `premium=1` 已开通，`premium=0` 未开通，`premium=refund` 模拟已退款
  - `papers=1` 恢复几个测试壁纸用的心愿
- 开关会存在本机：去掉启动参数后依然生效，要关得传 `mock=0`。
- 付款弹出「模拟支付」，不真扣款。
- 定课时长缩短到 1 分钟，「自己敲」里多出 1 分钟和 10 下两个选项。
- 不下载云端文件，所有声音都用合成的。
- 重新试用付费定课：在 Storage 面板删掉 `muyu_plan_tried`。

### 新增文件后报「module … is not defined」

在开发者工具外面新建的文件，可能没被编译进去，报 `module 'utils/xxx.js' is not defined`，接着报 `Page … has not been registered yet`。点工具栏「清缓存 → 全部清除」，再编译即可。

### 云函数

正在使用：

| 云函数 | 用途 |
|---|---|
| `login` | 首次进入时建用户 |
| `fetch` | 各页面读数据（首页、心愿、详情、静心） |
| `hit` | 记录敲击 |
| `wish` | 立愿、改愿等 |
| `user` | 保存设置，校验付费项 |
| `wxpay` | 静心包付款：下单、查单、退款复核 |
| `bindChannel` | 扫推广码时把用户归到渠道 |
| `activateChannel` | 渠道商申请、激活、解绑 |
| `channelAdmin` | 渠道管理后台 |
| `generateChannelQR` | 生成推广码 |
| `getChannelStats` | 渠道统计 |

- 后台工具（手动在控制台运行）：`initChannelDb`、`clearChannelDb`、`seedChannel`。
- 旧版，客户端已不调用：`pay`、`xpayNotify`（旧的虚拟支付），`createOrder`、`bindOperator`、`generateBindCode`、`checkChannelAuth`。

`wxpay` 的配置写在 `cloudfunctions/wxpay/secrets.js`（不入库，从 `secrets.example.js` 复制），也可以用环境变量覆盖：

| 配置项 | 环境变量 | 说明 |
|---|---|---|
| `appid` | `WXPAY_APPID` | 必填 |
| `mchid` | `WXPAY_MCHID` | 必填 |
| `serialNo` | `WXPAY_SERIAL_NO` | 必填 |
| `privateKey` | `WXPAY_PRIVATE_KEY` | 必填 |
| `price` | `WXPAY_PRICE` | 必填，单位分，至少 1 |
| `description` | `WXPAY_DESC` | 付款单描述 |

`channelAdmin` 和 `generateChannelQR` 需要 `wxacode.getUnlimited` 权限。
